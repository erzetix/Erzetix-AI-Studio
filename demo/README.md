# Демонстрационный интерфейс

Клиентский дашборд комплекса в демонстрационном исполнении. Рабочая версия: https://erzetix.github.io/Erzetix-AI-Studio/demo/ Также открывается локально файлом [`index.html`](index.html) без установки и настройки.

## Состав

Интерфейс реализует разделы, описанные в [спецификации дашборда](../dashboard/):

- **Кампании** — состояние кампаний в производственном конвейере, материалы выбранной кампании и журнал выполнения этапов
- **Утверждение** — материалы из всех кампаний, ожидающие решения в контуре Human-in-the-Loop
- **Показатели** — данные публикаций персонажа
- **Персонаж** — профиль персонажа; параметры идентичности отображаются как размещённые в защищённом хранилище

Поддерживаются три режима утверждения (ручной, гибридный, автономный) и режим гостевого входа, предусмотренный требованиями к подсистеме.

## Ограничения

Интерфейс работает на предустановленном наборе данных. Обращения к оркестратору и подсистемам комплекса не выполняются, решения об утверждении не сохраняются между сеансами.

Показатели публикаций соответствуют фактическим данным персонажа Ник. Состав кампаний и заключения проверки приведены в демонстрационных целях.
